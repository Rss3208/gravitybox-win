## 启动 SDD 开发的推荐第一步

1. 从当前 `main` 创建特性分支：`git checkout -b feat/windows-port`
2. 优先完成 [`T-001`（Day-0 Windows 宿主实机核验）](./03-execution.md#t-001-day-0-windows-宿主实机核验与常量冻结)，将 `CHK-01`–`CHK-05` 实测值回填至 [`02-design.md`](./02-design.md)。
3. 依次推进 `T-002`–`T-004` 打通双平台开发与测试基座后，即可按 [`03-execution.md §3`](./03-execution.md#3-里程碑路线图与依赖关系m0--m7) 并行推进后端 PAL（M1/M2）与 C# Win32 原生桥（M3）。
